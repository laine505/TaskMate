# Changelog

## Version Beta 1.0a

### Added Features
- Implemented an Admin Management feature where administrators can approve or reject user posts.
- Added a Working Orders screen that displays:
  - Tasks assigned to the worker
  - Tasks the user has applied for
- Workers can now mark assigned tasks as completed.
- Clients can now leave ratings and star reviews for workers after task completion.

### CRUD Improvements
- Fully implemented CRUD (Create, Read, Update, Delete) functionality for posts.
- Users can now properly:
  - Create posts
  - Edit posts
  - Delete posts
  - View posts

### Notification System Enhancements
- Improved notification functionality.
- Users can now view:
  - Notifications they have received
  - Notifications they have sent

### System Improvements
- Improved overall workflow and task management experience.
- Enhanced user interaction between clients and workers.
- Refined admin moderation and monitoring capabilities.
